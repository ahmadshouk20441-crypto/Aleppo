# خريطة النقل الداخلي لحلب — دليل تفاعلي

خريطة SVG تفاعلية لخطوط المواصلات داخل مدينة حلب، مع جهاز بحث عن الطرق
ولوحة إدارة لتحرير المحطات والخطوط وتصدير نسخة Viewer مستقلة للنشر.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء الإنتاج إلى dist/
npm test         # تشغيل الاختبارات (Vitest)
```

## بنية المشروع

```
index.html                 هيكل الصفحة (نسخة الأدمن)
src/main.js                نقطة الدخول: CSS + التطبيق
src/app.js                 التطبيق: الرسم والتفاعل ولوحة الأدمن
src/styles/main.css        نظام التصميم (RTL، الوضع الليلي)
src/data/map-data.js       بيانات الخريطة MAP_DATA (المحطات والخطوط)
src/core/text.js           تطبيع النص العربي للبحث
src/core/geometry.js       الإزاحة المتوازية والمسارات المنحنية
src/core/network.js        بناء أشواط الرسم وممرات الخطوط
src/core/routing.js        مخطط الشبكة وخوارزمية إيجاد المسار (دايكسترا)
tests/                     اختبارات توصيف وتطابق مع النسخة الأصلية
legacy/                    الملف الأحادي الأصلي (مرجع، لا يُعدَّل)
```

- لتعديل الخريطة (محطات/خطوط/ألوان/إحداثيات) عدّل `src/data/map-data.js` فقط.
- زر «تصدير للنشر» في الواجهة يولّد ملف HTML واحدًا مستقلًا (نسخة Viewer
  بلا أدوات تعديل) جاهزًا للرفع على أي استضافة ثابتة.
- اختبارات `tests/` تقارن سلوك الوحدات الجديدة حرفيًا مع
  `legacy/aleppo-transit-original.html` (البيانات، المسارات، الهندسة).
